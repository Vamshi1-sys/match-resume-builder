# ResuMatch AI — Match Resume Builder

ResuMatch AI is an AI-powered ATS resume builder and job description matching platform. It allows users to tailor their resumes specifically to any job description using the Google Gemini API.

## Features

- **AI Resume Tailoring**: Automatically optimize your professional summary, skills, work experience, and projects to align with a job posting.
- **ATS Quality Analysis**: View detailed ATS compatibility scores, strengths, weaknesses, and direct recommendations.
- **Structured Resume Editor**: Lock/unlock fields to manually refine extracted data.
- **Clean PDF/DOCX Downloads**: Export a professional, ATS-friendly resume layout with a single click.

## Deployed on Vercel

The backend API is designed as a standalone, Vercel-compatible serverless function under `/api`.

## Development

To run the application locally:

```bash
npm install
npm run dev
```

The app will run locally on `http://localhost:3000`.
